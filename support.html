Email: support@djhsi.com

Include your device (Mac/iPhone), iOS/macOS version, and a brief description of what happened — screenshots help a lot if it's a display issue.

Common questions

PDF statement import isn't extracting my statement correctly

Try a different parsing depth (Basic/Normal/Advanced) or a different AI engine in Settings — accuracy can vary by statement layout and provider. Apple Intelligence works fully offline but is limited to Basic/Normal depth.

My balances aren't syncing between my Mac and iPhone

Confirm iCloud is signed in and enabled on both devices, and that you have an internet connection on both. Sync happens via Apple's iCloud/CloudKit and can take a few minutes.

Do I need an API key to use TallyWorth?

No — manual entry and CSV import work with no API key at all. API keys (Claude, Gemini, or ChatGPT) are only needed if you want AI-powered PDF statement import using one of those providers. Apple Intelligence requires no key.

Where is my data stored?

On your own device and, if enabled, your own iCloud account. See our Privacy Policy for full details.
